# Documentation

This index groups the project’s technical method, generalized demo data, optional backend, and contributor workflows.

- [Deployment](deployment.md): static hosting and generic container contracts.
- [Local backend](local-backend.md): optional Docker/native setup, administrator bootstrap and persistent storage.
- [Site configuration](site-configuration.md): public operator notice and optional analytics.
- [Public/private boundary](public-private-boundary.md): publication checks and installation ownership.
- [Publication history guard](workflows/publication-history.md): ancestor audit and optional pre-push protection.
- [Architecture](architecture/architecture.md): application structure and extension boundaries.
- [Internationalization](architecture/i18n.md): language detection, catalogs, formatting, and browser tests.
- [Analytics and privacy](analytics.md): optional Umami, consent, `/privacy`, public configuration, events, and activation checks.
- [Property dossier architecture](architecture/property-dossier-architecture.md): deferred architecture options for the dossier.
- [Apartment model](model/apartment-geometry.md): geometry and measurement status.
- [Apartment placement](model/apartment-placement.md): provisional registration in the building.
- [Solar model](model/solar-model.md): calculations, time rules, and limitations.
- [Rooftop photovoltaics](model/photovoltaic-model.md): building installations, geographic generation, climate assumptions and financial scenarios.
- [Building research](research/building-research.md): geographic sources and attribution.
- [Property dossier](research/property-dossier.md): current editorial scope.
- [Property dossier research](research/property-dossier-research.md): source inventory and research notes.
- [Blender workflow](workflows/blender.md): scene assembly and validation commands.
- [Public demo](workflows/public-demo.md): movable furniture, browser persistence, reset and curated object history.
- [Apartment editor](workflows/apartment-editor.md): variants, furniture layouts, finishes, lighting and explicit project saves.
- [Private projects](workflows/private-projects.md): accounts, invitations, project access and deployment.
- [Asset mobility](workflows/asset-mobility.md): fixed/movable metadata and compatibility with existing projects.
- [First-person walkthrough](workflows/walkthrough.md): visiting active project versions, controls, temporary settings and collision limits.
- [Object workshop](workflows/local-asset-workshop.md): hosted OpenAI API, optional local Codex adapter, persistent queue, Blender generation and recovery.
- [Credits and development payments](credits-billing.md): trials, gifted premium access, invitation privileges, reservations, subscriptions and credit packs in ARS.
- [Server asset generation](research/server-asset-generation.md): feasibility, Codex and Blender integration, asset library architecture, and the first headless prototype.
- [README media](workflows/readme-media.md): reproduce the screenshots and GIFs for walking, furniture, object versions, private design, sunlight and rooftop energy.
- [Checkpoints](checkpoints/): resumable project state and decisions.
- [Reference evidence](reference/evidence.md): provenance and interpretation of visual evidence.
- [Snapshots](snapshots/): generated JSON inputs used by the Blender workflows and snapshot verification.

The apartment and building JSON snapshots are generated by `pnpm scene:snapshot`; run `pnpm scene:verify` to check that the checked-in snapshots match the canonical source data.
